# 汉化文本数据

这里用于保存可审查的中文文本与术语表；后续优先按 **源码内原始字符串/标识符** 进行映射，尽量避免通过固定 ROM 偏移写入。

旧的 Meowth 翻译数据 `texts_translated.json` 保存在先前的工作文件中。它包含原文、翻译、旧 ROM 地址与指针来源；**不能直接当作已适配 Emerald Arena 源码的最终汉化数据**。

由于原版 ROM 打入旧字库后会破坏部分 Arena 数据，禁止直接把这份旧数据写回目标 ROM。

下一阶段：提取确实完成翻译的条目、去重，生成源文本/中文对应表；并保留文本控制码与原有标点。绝对地址仅用于回溯，不作为最终构建接口。
